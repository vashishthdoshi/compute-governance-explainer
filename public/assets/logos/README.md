# Logos

The site shows a logo wherever a `logo_file` value in the workbook (Organizations or Approaches sheet) matches a file name here, ignoring the extension. Anything missing shows as initials.

- One entry can list several logos separated by semicolons, e.g. `boston-university;harvard;mit`. The first is the main badge; group entries show all of them in the detail panel and Stakeholders table.
- Files here are trimmed and resized to WebP, at most 480 × 200 px. SVG, PNG and JPG also work.
- Logos are trademarks of their owners and are used only to identify each organization.
